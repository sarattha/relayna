# Usage and provenance

This package was prepared for reuse across the Relayna product repositories at the project owner's request. It contains the selected Slim Leaf identity and original Relayna Portico and Relayna Round glyph outlines. Urbane Rounded served as a visual mood reference only: no Urbane font binary, outlines or proprietary metrics are distributed here.

The mark was generated during the Relayna identity exploration, selected by the owner, automatically traced to native contours, and retained through the color update. The warm connection ribbons are supporting artwork created for this system. See `provenance/` and the original font evidence under `source/typeface/evidence/`.

No public distribution license has been selected for the brand assets, font or package code. `private: true` prevents registry publication; `UNLICENSED` is package metadata, not an open-source license grant. Confirm an external distribution policy before publishing these assets to a public registry or redistributing the font outside the intended Relayna repositories.

The package has no runtime dependencies. Optional build tools keep their respective licenses and do not contribute proprietary glyph designs. Installed Python tools are not vendored. Source references: [FontTools](https://fonttools.readthedocs.io/), [HarfBuzz](https://harfbuzz.github.io/), [CairoSVG](https://cairosvg.org/) and [VTracer](https://github.com/visioncortex/vtracer).

Portico was expanded from the owner-selected F3 native Bezier wordmark study. Its new companion outlines and the reused original Relayna Latin composition infrastructure contain no third-party font outlines. See `docs/PORTICO.md` and `provenance/portico-family.json`.
